# Zerodha Clone

A full-stack stock trading platform inspired by Zerodha, built to demonstrate modern web development skills. The application includes a trading dashboard and interactive stock buy/sell functionality.

## 🚀 Features

- **Trading Dashboard:** View and manage stock-related information.
- **Buy & Sell Stocks:** Interactive interface for stock transactions.
- **Portfolio Management:** Organize and track stock holdings.
- **Responsive Interface:** User-friendly application layout.
- **Backend Integration:** Server-side functionality and database connectivity.

## 🛠️ Tech Stack

**Frontend**
- React.js
- JavaScript
- HTML5
- CSS3

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB

**Tools**

## ⚙️ Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/Anu-Jaiswal/Zerodha-Clone.git
```

2. Navigate to the project directory:

```bash
cd Zerodha-Clone
```

3. Install dependencies in the required project folders:

```bash
npm install
```

4. Configure the environment variables in the backend `.env` file.

5. Start the frontend, backend, and dashboard using their respective npm scripts.

## 🎯 Project Objective

The objective of this project is to build a full-stack stock trading application while gaining practical experience in frontend development, backend APIs, database integration, and application architecture.
